# Кодировочная книга МЭПВ-KPI

## 1. Назначение

Кодировочная книга описывает переменные, категории и правила кодировки для анализа медийных эпизодов прямого влияния (МЭПВ) в вооружённых конфликтах.

## 2. Единица анализа

**МЭПВ — медийный эпизод прямого влияния**: идентифицируемый комплекс сообщений, кампаний или медиасобытий, для которого зафиксирована временная, содержательная и институционально подтверждённая связь с измеримым результатом вне самой медиасистемы.

Важно: МЭПВ не доказывает линейную причинность. Он фиксирует включённость медийного действия в причинный механизм, связанный с изменением показателей других институциональных акторов.

## 3. Основные переменные

| Переменная | Тип | Описание |
|---|---|---|
| `episode_id` | string | уникальный идентификатор МЭПВ |
| `conflict` | categorical | конфликт, к которому относится эпизод |
| `date_media_action` | date/string | дата или период медийного действия |
| `date_outcome` | date/string | дата зафиксированного результата |
| `episode_type` | categorical | тип медийного эпизода |
| `kpi_category` | categorical | одна из пяти KPI-категорий |
| `media_action` | text | краткое описание медийного действия |
| `observable_outcome` | text | измеримый результат вне медиасистемы |
| `source_type` | categorical | тип источника подтверждения |
| `verification_status` | categorical | статус проверки источников |
| `attribution_level` | categorical | уровень атрибуции A/B/C/D |
| `alternative_explanations` | text | конкурирующие объяснения результата |
| `sensitivity_level` | categorical | уровень чувствительности данных |
| `included_in_article_table` | boolean | включён ли эпизод в таблицы статьи |

## 4. Шкала атрибуции

| Уровень | Название | Критерий |
|---|---|---|
| A | сильная атрибуция | актор прямо связывает решение или результат с информационной картиной / медийной кампанией |
| B | умеренная атрибуция | есть временная связь, независимые источники и совпадение нарративов |
| C | слабая атрибуция | связь вероятна, но альтернативные объяснения существенны |
| D | исключено | недостаточно данных для включения в датасет |

В итоговый корпус включаются эпизоды уровней A–C. Эпизоды уровня D фиксируются в журнале исключений или агрегированной статистике, но не используются для основных выводов.

## 5. KPI-категории

| KPI | Название | Краткое описание |
|---|---|---|
| KPI-1 / OSI | Operational Safety Information | информирование населения и гуманитарные коридоры |
| KPI-2 / DRI | Desertion and Resistance Influence | работа с военным контингентом противоборствующей стороны |
| KPI-3 / SRI | Surrender and Resistance Reduction | коммуникация с окружёнными подразделениями и условия капитуляции |
| KPI-4 / MAI | Military Assistance Influence | международная информационная кампания и решения о поддержке |
| KPI-5 / DCI | Defense Contracts Influence | демонстрация эффективности вооружений и оборонные контракты |

## 6. Правила кодировки

1. Один эпизод может относиться к нескольким типам событий.
2. Один эпизод может быть связан с несколькими KPI, если есть отдельные измеримые результаты.
3. При наличии конкурирующих объяснений кодировщик обязан заполнить `alternative_explanations`.
4. Сильные причинные формулировки избегаются: кодируется не “медиа вызвали результат”, а “медиа входят в причинный механизм”.
5. Чувствительные данные агрегируются или исключаются.
