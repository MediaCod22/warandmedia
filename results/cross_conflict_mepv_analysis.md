# Кросс-конфликтный анализ эпизодов

## Описание

Файл описывает распределение 46 уникальных медиа-эпизодов по типам событий и вооружённым конфликтам. Сумма по типам равна **99**, поскольку один уникальный эпизод может относиться к нескольким типам событий одновременно.

## Конфликты

- СВО
- Ближний Восток (Израиль — ХАМАС)
- Судан
- Мьянма
- Сирия
- Йемен

## Методологическое примечание

Показатель типовых вхождений не равен числу уникальных эпизодов. Он показывает, сколько раз эпизоды были отнесены к типам событий и KPI-категориям. Это позволяет учитывать комбинированные кампании, где один медийный эпизод одновременно влияет на несколько направлений.
