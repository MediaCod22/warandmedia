# Data Use Guidelines

## Разрешённое использование

Данные и материалы можно использовать для:

- проверки методологии исследования;
- академического цитирования;
- расширения кодировочной схемы;
- сравнительных исследований медиасистем и вооружённых конфликтов;
- преподавания методов Open Science и conflict communication analysis.

## Ограничения

Запрещается использовать материалы для:

- идентификации непубличных лиц;
- раскрытия уязвимых маршрутов, групп или источников;
- оперативного планирования вредоносных действий;
- публикации персональных данных;
- подстрекательства к насилию.

## Рекомендуемое цитирование

При использовании данных необходимо цитировать статью автора и конкретную версию репозитория.
